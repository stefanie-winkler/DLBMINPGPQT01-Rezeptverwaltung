# DLBMINPGPQT01-Rezeptverwaltung

Desktop-Anwendung zur digitalen Verwaltung von Koch- und Backrezepten, entwickelt mit Qt und C++ im Rahmen des Kurses "GUI-Programmierung mit Qt" (DLBMINPGPQT01).


## Funktionen
- Rezepte anlegen, ansehen, bearbeiten und löschen
- Filtern nach Titel, Kategorie oder Zutaten
- Automatisches Speichern und Laden über eine JSON-Datei


## Projekt öffnen
1. Qt Creator öffnen
2. Datei 'Rezeptverwaltung.pro' öffnen
3. Projekt bauen und ausführen
